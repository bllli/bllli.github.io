我比较推崇卡片笔记法，即每篇笔记只记录一件事儿 / 一个知识点， 标题应该足够详细
每篇笔记都有多个标签，通过标签为笔记建立索引
 两个插件 TagFolder / Fag Wrangler 
 卡片笔记的思想指导全部来自 浮墨笔记的《笔记的方法》 https://help.flomoapp.com/thinking/start.html
但是浮墨比较纯粹，记录代码特别费劲，我就用的 obsidian

图片绘制上， 草图 Excalidraw / UML图（流程图/时序图。。） PlantUML
这两个不在obsidian里也能用，不过有了obsidian插件就很方便

整理笔记文件格式 用的 Linter 插件
这个主要用于将笔记正文中的标签收纳到 笔记的参数区。

这是因为 我的笔记转博客网站模板只能这样配置才能正确展示标签列表

我的博客是 https://bllli.github.io/ 

Chronology 展示一个日历，能看每天/每小时新建/更新了哪些笔记，还有一个简单的计数功能

还有一个神器 Dataview  在很多笔记上写属性。在写汇总笔记时可以用特殊的SQL-like语法将有某些属性笔记查询出来 这个我没用明白呢，但舍不得删掉

最后一个 Git 
配置好git仓库后，这个插件能定时自动 commit / push
